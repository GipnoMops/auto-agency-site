# AutoAgency — Europe car sourcing landing page

Static website built with HTML, CSS and vanilla JavaScript.

## Run locally

Open `index.html` in a modern browser. Google Fonts, stock photography and the embedded map require an internet connection.

## Files

- `index.html` — page structure and content
- `style.css` — layout, styling and responsive breakpoints
- `script.js` — PL/EN/RU translations, mobile navigation and form message generation
- `images/favicon.svg` — custom favicon

## Form behavior

The form does not submit to a server. It prepares a message and opens the visitor's email app or WhatsApp. Contact information is embedded from the supplied original website.

## Notes

Stock photos are loaded from Unsplash URLs. Tax-related content is worded as transaction-dependent; the final copy should still be approved by the business owner before publication.
